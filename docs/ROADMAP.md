# Roadmap mod-jam

## Phase 1 — Items et blocs de base

Objectif : voir des trucs en jeu vite.

- `excavation_table`
- `dino_jungle_map`
- item group créatif du mod
- models JSON simples

## Phase 2 — Table de fouille

Objectif : boucle simple “je mets un item, ça raconte un truc”.

- clic droit avec item du mod en main
- message chat/actionbar avec une description

## Phase 3 — Premier mob

Objectif : un mob testable.

- EntityType
- attributs
- spawn egg
- renderer/model temporaire ou modèle simple
- spawn command / creative tab

## Phase 4 — Archéologue

Objectif : villageois utile même sans structure finale.

Trades essentiels :

- achète `bone` contre emeralds
- vend `sniffer_egg`
- vend `dino_jungle_map`
- vend graines anciennes / items archéo

## Phase 5 — Loot archéologique

Objectif : obtenir les œufs par fouille.

- loot tables pour suspicious sand/gravel/dirt du mod ou variantes placées dans la structure
- premières récompenses : œufs, os, fossiles, graines

## Phase 6 — Dino Dino Jungle

Objectif : le gros showcase.

Version pragmatique :

- structure unique type room/cavern préfabriquée
- parois organiques pierre/tuff/deepslate/mousse/rooted dirt
- jungle vanilla dedans
- suspicious blocks
- spawns de mobs

## Phase 7 — Calmar géant

Objectif : feature bonus visible hors structure.

- spawn rare en deep ocean
- plusieurs nautiles autour
- comportement simple : suit/attaque/protège zone

- sons
- particules
- textures
- advancements
- équilibrage trades / loot
